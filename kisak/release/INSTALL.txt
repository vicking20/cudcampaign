CUDCAMPAIGN - campaign co-op  (built on KisakCOD)
===========================================

You need your own copy of the 2007 single-player game this was built for. Nothing from the game is in this zip.

1. Unzip so that the "coop" folder sits INSIDE your game folder, next to "main" and "zone":

      Game folder\
          main\   zone\   players\   ...
          coop\          <-- this folder
              KisakCOD-sp.exe

2. First time only: run coop\install.ps1 (Windows: right click -> Run with PowerShell) or coop/install.sh (Linux).
   It downloads the audio/video/Steam runtime files the exe needs (list and checksums in deps.txt; edit the BASE line to change the source).

3. Run  coop\KisakCOD-sp.exe  - the launcher window opens. Pick:
      Single player / Host (direct) / Join (direct) / Host online / Join online
   Everyone playing needs the same version of this zip.

Online play needs a relay server (relay\relay.py, Python 3) running somewhere everyone can reach. See relay\README.md.
Linux / Steam Deck: install Wine, then run coop/play-linux.sh (DXVK is bundled in coop/linux/, nothing to configure).
  play-linux.sh runs the game inside a Wine "virtual desktop" window (only for that run, nothing is saved); it stops
  desktop popups stealing the game's focus on KDE/Wayland. Not needed with gamescope or Steam/Proton. Off: CUD_DESKTOP=0 ./play-linux.sh
  Steam alternative: add KisakCOD-sp.exe as a non-Steam game and force a Proton version.
